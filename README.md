# موقع د. حمد الذيابي

موقع شخصي ثنائي اللغة (العربية افتراضيًا + English) لـ د. حمد الذيابي، قائد في الذكاء الاصطناعي والتحول الرقمي بالقطاع الحكومي.
الموقع يحكي قصته وشخصيته، مو سيرة ذاتية، وكل معلومة فيه مأخوذة من بروفايله على لينكدإن.

**الفكرة البصرية: «التقارب».** مسارات ذهبية على سماء نجد الليلية تتجه كلها لنقطة واحدة، متل ما بتتفق الشبكات على طريق واحد (موضوع الدكتوراه تبعه)، ومتل الفروع اللي ربطها بالمقر بالرياض. الألوان من البانر تبعه (نيلي غامق) ومن إطار صورته (ذهبي)، والحافة بين الأقسام شُرفات نجدية.

## الصفحات

| الصفحة | الملف | شو فيها |
|---|---|---|
| الرئيسية | `index.html` | صورته وسط مسارات متقاربة، القصة باختصار، أرقام بتعد، ما يقوده، كيف يفكّر، سؤال الدكتوراه برسم متحرك، محطات التقدير، دعوة للتواصل |
| المسيرة | `journey.html` | قصته بثمانية فصول من مكة لقيادة الذكاء الاصطناعي، والخط الذهبي بيطلع برّا بسنين الابتعاث وبيرجع |
| الأثر | `impact.html` | الذكاء الاصطناعي، الخدمات والتعاملات الإلكترونية، البنية التحتية والشبكات، ومجالات التركيز |
| البحث | `research.html` | شرح مبسّط لمشكلة تقارب BGP مع رسم متحرك (BGP التقليدي / مع SDN)، أبحاثه، 30,000 قارئ، تقييم تدريسه، مؤهلاته |
| تواصل | `contact.html` | بطاقة تواصل (لينكدإن)، وأسئلة شائعة بتفيد محركات البحث والذكاء الاصطناعي |

النسخة الإنكليزية بنفس الأسماء جوّا مجلد `en/`. زر اللغة بيحفظ اختيار الزائر وبيرجّعه لنفس القسم اللي كان فيه، وزر القمر بيبدّل للوضع الليلي وبيتذكّره.

## وين بتعدّل

- **النصوص:** كلها بملف `content.py`. كل نص زوج: `t("عربي", "English")`.
- **الإعدادات:** أول ملف `build.py` بقسم `CONFIG`:
  - `BASE_URL` رابط الموقع الحي.
  - `PHOTO` الصورة (جوّا `src/assets/img`). إذا فضّيتها بيطلع حرف بدالها.
  - `EMAIL` و`PHONE` و`WHATSAPP` فاضيين هلأ عن قصد، لأن إيميله ورقمه ظاهرين بلينكدإن لجهات الاتصال بس. أي قيمة بتعبّيها بتظهر لحالها بصفحة التواصل والفوتر.
  - `LINKEDIN` رابط بروفايله.
  - `MAKER` رابط موقعك بالفوتر.
  - `PREVIEW = True` يعني الموقع مخفي عن محركات البحث (noindex + robots.txt بيمنع الزحف). **لما يوافق د. حمد خليها `False`** وابنِ من جديد، فبيصير `robots.txt` يرحّب بـ GPTBot وClaudeBot وPerplexityBot وGoogle وغيرهم.
  - `DOMAIN` لما يصير عنده دومين خاص.
- **الشكل:** `src/assets/style.css` (الألوان كلها متغيرات بأول الملف). **الحركة:** `src/assets/site.js`.

بعد أي تعديل:

```bash
python3 build.py        # بيكتب الموقع الجاهز بمجلد docs/
```

## النشر

الموقع منشور على GitHub Pages من مجلد `docs/` بفرع `main`. أي `push` بيحدّث الموقع خلال دقيقة تقريبًا.

**دومين خاص (مثلًا `hamad-althiapi.com`):**
1. حط الدومين بـ `CONFIG["DOMAIN"]` وغيّر `BASE_URL` لـ `https://الدومين/` وابنِ.
2. بإعدادات الدومين: سجل `CNAME` لـ `www` بيأشّر على `nouraldeentofi.github.io`، و4 سجلات `A` للدومين الأساسي: `185.199.108.153` و`185.199.109.153` و`185.199.110.153` و`185.199.111.153`.
3. بالريبو: Settings ← Pages ← Custom domain، وفعّل Enforce HTTPS.

## الذكاء الاصطناعي ومحركات البحث

كل المحتوى مكتوب جوّا الـ HTML (الزواحف ما بتشغّل JavaScript). بكل صفحة JSON-LD لشخص (Person) فيه كل طرق كتابة اسمه بالعربي والإنكليزي، وظائفه بمرادفاتها، مؤهلاته، جوائزه، وأبحاثه (ScholarlyArticle)، وصفحة التواصل فيها FAQPage مطابقة للأسئلة الظاهرة. وفي `llms.txt` و`llms-full.txt` و`sitemap.xml` مع hreflang، وصورة مشاركة `og.jpg`.
